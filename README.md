
# Rule-Based Interactive Terminal Assistant / Chatbot

## Project Description
This project is a Python-based customer support chatbot.
It recognizes user queries using keywords and regular
expressions and provides appropriate responses.

## Features
- Greeting responses
- Business hours information
- Product FAQs
- Return policy information
- Keyword recognition
- Regular expression matching
- Fallback responses
- Exit commands

## Technologies Used
- Python 3
- Regular Expressions
- JSON

## How to Run
1. Download the project.
2. Open the project folder in VS Code.
3. Run the following command:

python chatbot.py
